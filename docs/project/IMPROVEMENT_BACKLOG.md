## 优先级定义

- **P0**：可能造成数据错误、重复/丢失通知、权限问题或无法安全上线。
- **P1**：明显影响可靠性、性能、用户完成任务的效率或日常维护。
- **P2**：文档、目录、文字和长期维护优化，不应阻塞核心业务修复。

## 当前明确不扩大的范围

以下内容不是本清单的下一阶段目标：

- 更换数据库或 Web 框架；
- 引入 Redis、Celery、Kubernetes 或微服务；
- 强行迁移 React、Vite 或复杂前端构建链；
- 一次性移动所有目录或重写所有大文件；
- 跨重启保存校园登录态；
- 将自动选课变成默认核心能力（2026-09-20 用户确认：自动选课目前不搞，相关代码只做清债维护，不安排专项验证，不做新投入）；
- 删除旧字段、旧 URL 或用途未确认的数据。

这些范围以后是否调整，需要新的需求、收益、风险、成本和回滚评估，不能因为“技术上可行”就自动进入实施。
