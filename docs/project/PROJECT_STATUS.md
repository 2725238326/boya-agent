## 项目用于什么

帮助北航同学发现合适的博雅课程，并在真实退选释放名额时收到补位提醒。公开网页负责查课、筛选和核对采集时间，飞书群负责课程卡片，报名由同学在官方系统完成。运维异常和恢复单独交给 Telegram。

- 采集区分有课、无课、认证失效、上游故障、解析失败和超时；异常快照不覆盖可靠数据。

- 预发布使用 fixture、独立数据库/日志/上传和文件邮件，阻断真实校园与通知连接。
