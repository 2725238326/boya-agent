# ADR 0004：二维码先审核，公开数据与私有数据分离

- 状态：已采用
- 日期：2026-09-02
- 相关代码：`src/qrcode_service.py`、`src/models.py`、`web/qrcode_feature.py`

## 背景

二维码上传包含图片内容、原始文件名、贡献者邮箱、课程关联和审核状态。上传成功不能自动代表内容可信或应当公开；把 ORM 对象直接序列化也容易把邮箱、服务器路径和审核字段暴露给公开接口。

## 决定

只有已验证且 active 的门户会话可以上传，贡献者从 Cookie 对应的订阅者取得，客户端传来的邮箱不作为身份依据。文件限制扩展名、实际图片格式、大小、尺寸、路径和 SHA-256 重复；文件写入日期目录和随机文件名。新记录为 `pending`，只有管理员审核为 `approved` 且仍 active、课程未过期时，公开列表和文件路由才可读取。

公开 DTO 不包含完整邮箱、原始文件名、MIME、路径、哈希或审核字段；管理员审核接口才返回这些私有字段。`course_id` 和 `content_hash` 通过兼容迁移补列和索引，不删除已有数据。

## 后果

- 上传成功页面必须明确提示“等待审核”，不能承诺立即共享。
- 过期课程的二维码会从公开列表和文件路由消失；历史记录仍可由管理员查看。
- 当前没有公开举报流程；下架由管理员把状态设为 `rejected` 或 `expired` 完成。
