# ADR 0005：本地预发布隔离与邮件分阶段开放

日期：2026-10-22。状态：已实现，本地验证；生产尚未发布。

现有邮件总开关同时控制登录、验证和课程通知，使“开放门户登录但继续暂停群发”只能靠数据库开关和人工约定。本地预发布也缺少运行时隔离，直接运行主入口会访问真实课程系统。

邮件保留 `EMAIL_DELIVERY_ENABLED` 总开关，新增 `EMAIL_DELIVERY_SCOPE=auth|all`。未配置 scope 时保持旧版 all 行为；非法值全部拒绝。auth 只允许 verify/login，后台手动通知及 email outbox 不领取，避免等待中的任务消耗重试次数。恢复通知须另改 scope 与数据库业务开关。

本地预发布使用显式启动器，在导入模型和 Web 之前设置独立运行路径、随机开发密钥、loopback 端口、fixture 抓取与 dry-run 邮件。启动器清除继承的校园、SMTP 与 Telegram 配置，main 不加载 .env。所有文件路径必须位于 STAGING_ROOT 内；不符合条件时拒绝启动。真实浏览器和 Telegram 创建入口另行拒绝 staging 调用。生产环境拒绝 dry-run 配置。

邮件 dry-run 保存标准 .eml，本地测试可以读取验证码并完成真实 Web 验证流程。文件含测试验证码与操作链接，使用排除版本控制的 runtime 目录；Linux 文件权限为 0600，Windows 使用目录继承 ACL。文件模式成功仅表示本地写入成功，不表示外部邮件送达。

SMTP 每次投递尝试一次主通道，必要时尝试配置不同的备用通道；后续重试交给 outbox。两种 TLS 模式都校验证书；异常关闭连接，DATA 已接受后的清理错误不触发重发。后台发送通过线程执行，避免阻塞调度事件循环。SMTP socket 单步超时 10 秒，不是整封邮件的绝对总耗时上限。

保持 Flask、单进程调度、SQLite 与现有 URL，不引入外部队列。跨进程资源模型、真实 SMTP 长期可达性和绝对不重复投递仍不作承诺。验证/登录邮件仍在 Web 请求中发送，数据库与 SMTP 不是同一个事务；生产恢复必须进行限定收件人的端到端验收。
